# Research log

Every claim the team might state in a paper, talk or README, with its evidence and status. The board issue is replaced every phase; this file stays.
Newest first. One entry per claim, including negative and inconclusive results. Don't edit old entries: if a result changes, add a new entry that says it replaces the old one.
